# SQL Case Study Assignments

A collection of SQL practice assignments solving real-world style business problems using SQL Server.

## 📁 Contents

- **SQL_Case_Study_Sales_Order_Processing.pdf** — Sales Order Processing System for a retail business (ABC Fashion). Covers table design, primary/foreign key constraints, default & not-null constraints, SET operators (UNION vs UNION ALL), and multi-table JOINs (INNER JOIN, RIGHT JOIN).

- **SQL_Case_Study_Jomato_Dataset.pdf** — Restaurant analytics case study using a food-delivery dataset (Jomato). Covers user-defined functions (STUFF), CASE statements for rating classification, date & math functions (CEILING, FLOOR, ABS, GETDATE), and grouping with ROLLUP.

- **Jomato.csv** — Dataset used in the restaurant analytics case study (7,104 rows, 12 columns: restaurant name, type, rating, cost, cuisine, area, etc.).

## 🛠️ Tools Used

SQL Server (T-SQL)
